# عيادة العلي — نظام إدارة فحص النظر والبصريات

## طريقة التشغيل محلياً

```bash
# 1) فك الضغط عن الملف ثم افتح المجلد
cd alnather

# 2) تثبيت الحزم (يتطلب Node.js 18+)
npm install

# 3) تشغيل السيرفر المحلي
npm run dev
```

ثم افتح المتصفح على: **http://localhost:3000**

سجّل الدخول بأي بيانات (النظام تجريبي حالياً بدون تحقق فعلي) واضغط "تسجيل الدخول".

## البنية

- `app/` — صفحة الدخول + الـ layout الرئيسي (Next.js App Router)
- `components/` — المكوّنات المشتركة (Sidebar, Topbar, Modal, ExamForm...)
- `screens/` — كل شاشة من شاشات النظام (Dashboard, Patients, Invoices...)
- `lib/` — بيانات تجريبية (`data.js`) ودوال مساعدة (`utils.js` — واتساب، طباعة PDF)
- `schema.sql` — مخطط قاعدة البيانات الكامل (PostgreSQL)

## ملاحظة مهمة

هذا النظام يعمل حالياً على بيانات تجريبية (in-memory) داخل المتصفح — أي تعديل يختفي عند تحديث الصفحة.
للانتقال لنظام إنتاجي حقيقي:

1. أنشئ قاعدة بيانات (مثلاً Supabase أو أي PostgreSQL) وطبّق عليها `schema.sql`.
2. استبدل الاستدعاءات من `lib/data.js` بنداءات API فعلية (Prisma أو Supabase client).
3. أضف نظام تسجيل دخول حقيقي (NextAuth أو Supabase Auth).
4. اربط زر واتساب بـ WhatsApp Cloud API بدل رابط `wa.me` المباشر.
