# عيادة العلي — نظام إدارة فحص النظر والبصريات

## التشغيل المحلي

يتطلب المشروع Node.js 18 أو أحدث.

```bash
cd alnather
npm install
npm run dev
```

للتشغيل الأقرب للإنتاج:

```bash
npm install
npm run build
npm start
```

يفتح النظام محلياً على `http://localhost:3000`.

## تشغيل الهاتف والآيباد على نفس البيانات

شغّل النظام على جهاز واحد داخل العيادة، واجعل الهاتف والآيباد على نفس شبكة Wi‑Fi. لأن أوامر `dev` و`start` تستمع على كل واجهات الشبكة، يمكن فتح النظام من الأجهزة الأخرى باستخدام عنوان IP لجهاز التشغيل:

```text
http://192.168.1.10:3000
```

استبدل `192.168.1.10` بعنوان الجهاز المضيف. في Windows استخدم `ipconfig` لمعرفة العنوان، وفي Linux استخدم `hostname -I`.

البيانات المشتركة تحفظ في:

```text
data/clinic-data.json
```

الحل لا يحتاج إنترنت أو سيرفر خارجي، لكنه يحتاج جهازاً مضيفاً واحداً يعمل داخل شبكة العيادة. إذا توقف الجهاز المضيف، يتوقف الوصول إلى البيانات المشتركة حتى يعود تشغيله. لا تستخدم `localhost` من الهاتف؛ استخدم IP الجهاز المضيف.

## النسخ الاحتياطي

انسخ مجلد `data` دورياً إلى قرص أو جهاز آمن. شاشة الإعدادات توفر كذلك تصدير واستيراد نسخة احتياطية. توجد نسخة `localStorage` محلية كخطة بديلة عند انقطاع الخادم، لكن المصدر المشترك الأساسي هو ملف `data/clinic-data.json` على الجهاز المضيف.

## البنية

- `app/` — صفحات Next.js وواجهة API المحلية.
- `app/api/data/route.js` — API التخزين المحلي المشترك.
- `components/` — المكوّنات المشتركة مثل Sidebar وTopbar وModal.
- `screens/` — شاشات المرضى والفحوصات والفواتير والمخزون والتقارير.
- `lib/api.js` — طبقة البيانات الهجينة مع fallback محلي.
- `lib/storage.js` — إعدادات التخزين والبيانات الافتراضية.
- `schema.sql` — مخطط PostgreSQL للانتقال المستقبلي إلى قاعدة بيانات كاملة.

## ملاحظات مهمة

- التطبيق يعمل محلياً من دون ربط خارجي.
- الفواتير تمنع إضافة كمية تتجاوز المخزون، وتخفض الكمية بعد الحفظ.
- حذف الفاتورة يعيد كمياتها إلى المخزون.
- الشاشة الحالية تحفظ في عنوان الصفحة ولا تضيع عند التحديث.
- يجب إبقاء الجهاز المضيف قيد التشغيل عند استخدام الهاتف والآيباد.
